### 静态变量的存储位置和计算

在做题之前，先记录一下回答错的C的知识，简单来说就是在函数内部静态定义了一个变量，之后再调用这个函数的时候，每次对这个变量自加并打印，会显示什么，我当时以为每次定义变量时都会重写变量，所以回答每次的结果都是一样的，后来面试官让我现场实验我才发现我错了，每次输出的数据都会自增，现在我来记录一下原因。

C语言中，如果在函数内部使用 `static`关键字定义一个变量，例如 `static int a = 0;`，这个变量会具有以下特点：

1. **静态存储周期** ：变量 `a`的生命周期是整个程序运行期间，即使函数返回，变量 `a`的值也不会被销毁，而是保留原来的值。
2. **局部作用域** ：变量 `a`的作用域依然是函数内部，不能在函数外部直接访问。

如以下的函数：

```c
void increment_and_print() {
    static int a = 0; 
    a++;
    printf("%d\n", a); 
}

```

连续调用三次，其输出结果会是

```
1
2
3
```

这里需要说明一下，在C语言中，**静态变量**存储在 **静态存储区** （也称为 **全局数据区** ），具体细分为以下两部分：

1. **数据段（Data Segment）**
  - 如果静态变量有显式初始化（如 `static int a = 0;`），它会存储在 **已初始化的静态存储区** 。
  - 初始化值在程序加载时被写入对应的内存区域，程序运行时直接使用。
2. **BSS段（Block Started by Symbol）**
  - 如果静态变量没有显式初始化（如 `static int b;`），它会存储在 **未初始化的静态存储区** 。
  - 静态变量默认初始化为 **零** ，即在程序加载时，该区域的所有字节会被清零。

所以我们的静态局部变量被存储在数据段中，而且初始化指令只会执行一次，这就是为什么 `a`会自增而不是永远输出1。

**逐步分析：**

1. 第一次调用函数时：
  - 静态变量 `a`被初始化为 `0`（仅在程序执行到此处第一次调用时初始化一次）。
  - 执行 `a++`，`a`变为 `1`。
  - 打印 `a`的值，输出 `1`。
2. 第二次调用函数时：
  - 变量 `a`已经存在，并且值为上次调用后的 `1`。
  - 执行 `a++`，`a`变为 `2`。
  - 打印 `a`的值，输出 `2`。
3. 第三次调用函数时：
  - 变量 `a`的值为上次调用后的 `2`。
  - 执行 `a++`，`a`变为 `3`。
  - 打印 `a`的值，输出 `3`。

### 回溯法求解数组分割问题

问题很简单，给一个数组 `a[]`，要求将其分割为两个和值相等的数组 `b[]`和 `c[]`。

这个问题是回溯法的经典运用，首先我们可以确定数组a\[\]的和值必须是偶数，不然一定没有答案。然后我们将 `a[]`的和除以二，就可以得到需要达到的数组和 `target`，只要能够找到一组符合要求的数组，那剩下的元素必然和值为 `target`，如果不是 `target`，说明条件是不成立的。这里我们要递归地寻找元素，然而每次递归之后都要恢复现场，这就是回溯法。

由于当时虽然想到使用回溯法，但脑子实在有点太紧张，以至于写的很慢而且没想清楚具体的代码结构，所以最后也只写了个大体的递归结构出来，被面试官叫停了，希望面试官能看到接下来我完善后的代码。

需要说明的是，由于最后的拆分步骤需要识别哪些元素已经被加入到 `b`中从而将剩余元素构建成 `c`，使用一个布尔类型数组 `used`来识别哪些元素是b使用的，这一数组也需要进行回溯。

代码及注释如下，这份代码命名比较抽象，可读性比较差，可以看后面规范化后的代码：

```c
#include <stdio.h>
#include <stdbool.h>

int sum(int a[], int length) {
    int array_sum = 0;
    for (int i = 0; i < length; i++) {
        array_sum += a[i];
    }
    return array_sum;
}

// 尝试将数组a从索引index开始拆分到数组b中，使得b的和为target
bool add_element(int a[], int length, int index, int target, int current, int b[], int *b_index, bool used[]) {
    if (current == target) {
        return true;
    }
    if (index >= length || current > target) {
        return false;
    }

    // 尝试加入当前元素到b中
    if (!used[index]) {
        used[index] = true; // 标记为已使用
        b[*b_index] = a[index];
        (*b_index)++;
        if (add_element(a, length, index + 1, target, current + a[index], b, b_index, used)) {
            return true;
        }
        // 回溯，移除当前元素
        (*b_index)--;
        b[*b_index] = 0;
        used[index] = false;
    }

    // 跳过当前元素
    return add_element(a, length, index + 1, target, current, b, b_index, used);
}

bool find_one_array(int a[], int length, int b[], int *b_length, int c[], int *c_length) {
    int total_sum = sum(a, length);
    if (total_sum % 2 != 0) {
        return false; // 总和为奇数无法平分
    }

    int target = total_sum / 2;
    int b_index = 0;

    // 使用一个布尔数组跟踪是否使用过某个元素
    bool used[length];
    for (int i = 0; i < length; i++) {
        used[i] = false;
    }

    if (!add_element(a, length, 0, target, 0, b, &b_index, used)) {
        return false; // 无法找到满足条件的b数组
    }

    *b_length = b_index;

    // 构建数组c（a中剩余的元素）
    int c_index = 0;
    for (int i = 0; i < length; i++) {
        if (!used[i]) {
            c[c_index++] = a[i];
        }
    }

    *c_length = c_index;
    return true;
}

int main() {
    int a[] = {1, 5, 11, 5, 0};
    int length = sizeof(a) / sizeof(a[0]);

    int b[length];
    int c[length];
    int b_length = 0;
    int c_length = 0;

    if (find_one_array(a, length, b, &b_length, c, &c_length)) {
        printf("Array b: ");
        for (int i = 0; i < b_length; i++) {
            printf("%d ", b[i]);
        }
        printf("\nArray c: ");
        for (int i = 0; i < c_length; i++) {
            printf("%d ", c[i]);
        }
    } else {
        printf("Error! \n"); // 说明条件错误。
    }

    return 0;
}

```

```c
#include <stdio.h>
#include <stdbool.h>

// 计算数组元素的总和
int calculate_sum(int array[], int size) {
    int total_sum = 0;
    for (int i = 0; i < size; i++) {
        total_sum += array[i];
    }
    return total_sum;
}

// 尝试将数组array从索引start_index开始拆分到subarray中，使得subarray的和为target_sum
bool try_split_array(int array[], int size, int start_index, int target_sum, int current_sum, int subarray[], int *subarray_size, bool element_used[]) {
    if (current_sum == target_sum) {
        return true;
    }
    if (start_index >= size || current_sum > target_sum) {
        return false;
    }

    // 尝试将当前元素加入到subarray中
    if (!element_used[start_index]) {
        element_used[start_index] = true; // 标记为已使用
        subarray[*subarray_size] = array[start_index];
        (*subarray_size)++;
        if (try_split_array(array, size, start_index + 1, target_sum, current_sum + array[start_index], subarray, subarray_size, element_used)) {
            return true;
        }
        // 回溯，移除当前元素
        (*subarray_size)--;
        subarray[*subarray_size] = 0;
        element_used[start_index] = false;
    }

    // 跳过当前元素
    return try_split_array(array, size, start_index + 1, target_sum, current_sum, subarray, subarray_size, element_used);
}

// 尝试将数组拆分为两个和相等的子数组
bool split_array_into_equal_sums(int array[], int size, int subarray1[], int *subarray1_size, int subarray2[], int *subarray2_size) {
    int total_sum = calculate_sum(array, size);
    if (total_sum % 2 != 0) {
        return false; // 总和为奇数无法平分
    }

    int target_sum = total_sum / 2;
    int subarray1_index = 0;

    // 使用一个布尔数组跟踪是否使用过某个元素
    bool element_used[size];
    for (int i = 0; i < size; i++) {
        element_used[i] = false;
    }

    if (!try_split_array(array, size, 0, target_sum, 0, subarray1, &subarray1_index, element_used)) {
        return false; // 无法找到满足条件的subarray1
    }

    *subarray1_size = subarray1_index;

    // 构建subarray2（array中剩余的元素）
    int subarray2_index = 0;
    for (int i = 0; i < size; i++) {
        if (!element_used[i]) {
            subarray2[subarray2_index++] = array[i];
        }
    }

    *subarray2_size = subarray2_index;
    return true;
}

int main() {
    int array[] = {1, 5, 11, 5, 0};
    int size = sizeof(array) / sizeof(array[0]);

    int subarray1[size];
    int subarray2[size];
    int subarray1_size = 0;
    int subarray2_size = 0;

    if (split_array_into_equal_sums(array, size, subarray1, &subarray1_size, subarray2, &subarray2_size)) {
        printf("Subarray 1: ");
        for (int i = 0; i < subarray1_size; i++) {
            printf("%d ", subarray1[i]);
        }
        printf("\nSubarray 2: ");
        for (int i = 0; i < subarray2_size; i++) {
            printf("%d ", subarray2[i]);
        }
    } else {
        printf("Error! \n"); // 说明条件错误。
    }

    return 0;
}
```
