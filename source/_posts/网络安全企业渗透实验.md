### 使用weblogic java 反序列化利用工具获取权限

**序列化和反序列化的含义**

序列化：把对象转化为可传输的字节序列过程
反序列化：把字节序列还原为对象的过程
序列化的目的是为了对象可以跨平台存储和进行网络传输

首先在/home/Hack文件夹下找到反序列化利用工具WebLogic_EXP.jar

![1715929233331](/image/%E7%BD%91%E7%BB%9C%E5%AE%89%E5%85%A8%E4%BC%81%E4%B8%9A%E6%B8%97%E9%80%8F%E5%AE%9E%E9%AA%8C/1715929233331.png)

使用工具的指令如下：

```bash
java -jar WebLogic_EXP.jar
```

![1715929758563](/image/%E7%BD%91%E7%BB%9C%E5%AE%89%E5%85%A8%E4%BC%81%E4%B8%9A%E6%B8%97%E9%80%8F%E5%AE%9E%E9%AA%8C/1715929758563.png)

输入Host和Port连接目标主机，并执行 `ls -al`命令，成功显示当前目录

![1715929870323](/image/%E7%BD%91%E7%BB%9C%E5%AE%89%E5%85%A8%E4%BC%81%E4%B8%9A%E6%B8%97%E9%80%8F%E5%AE%9E%E9%AA%8C/1715929870323.png)
