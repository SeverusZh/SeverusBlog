# Severus' Blog

个人技术博客，记录学习与折腾的过程。

**🌐 https://severuszh.github.io/SeverusBlog/**

## 内容

- **博客搭建** —— Hexo、GitHub Pages，以及图片、评论、搜索等配置踩坑
- **网络安全** —— 课程实验记录：网络侦察、企业渗透、防火墙、VPN、入侵检测、漏洞挖掘
- **Hawk 实现优化** —— 签名与验签部分的 AVX2 向量化优化笔记
- **LeetCode / 面试题** —— 题解与思路，偶尔的逆向分析记录

## 技术

- [Hexo](https://hexo.io) 8 + [hexo-theme-cards](https://github.com/ChrAlpha/hexo-theme-cards) 主题
- 文章源码在 `source/_posts/`，配图在 `source/image/`
- 推送到 `main` 后由 GitHub Actions 自动构建并发布到 GitHub Pages
